Document Processing
Module 1B · Cloud Function (push sub)
Document AI Form Parser OCR Confidence Gate 0.75 Firestore
  • Triggered by Pub/Sub: raw-eviction-filings push subscription
  • Route by format: PDF → Document AI Form Parser · Image → OCR Processor · XML/JSON → direct schema map
  • Extract 13 structured fields with per-field confidence scores
  • Confidence ≥ 0.75: write to Firestore: eviction_filings (set/merge, idempotent) + publish Pub/Sub: structured-filings-ready
  • Confidence < 0.75: partial write + route to Pub/Sub: low-confidence-filings (human review)

Gemini Legal Analysis
Module 2 · Cloud Function + Vertex AI
Gemini 1.5 Pro 12 Defense Types BQML Probabilities Pydantic Validation Jurisdiction YAML
  • Load JurisdictionRuleset from GCS (PA-UJS.yaml or CA-COURTS.yaml, cached in-memory)
  • Lookup landlord behavioral profile → BigQuery: evictionshield.landlord_profiles
  • Fetch defense probability scores → BQML: defense_effectiveness_model (logistic regression)
  • Build prompt: BASE_SYSTEM_PROMPT + jurisdiction rules + user filing data + landlord profile
  • Call Gemini 1.5 Pro with response_mime_type="application/json"
  • Pydantic validate → EvictionAnalysisResult (12 defense types, legal basis citations, disclaimer)
  • On schema failure: automatic correction-prompt retry (max 1 attempt)
  • Write → Firestore: case_analyses/{case_number} (idempotent)
  • Publish → Pub/Sub: case-analysis-complete

Tenant SMS Notification
Module 4A · Cloud Function + Twilio
Twilio SMS Gemini Flash 4 Languages Cloud Tasks Privacy: Phone Hash
  • Triggered by new Firestore: case_analyses document
  • Detect tenant language via ZIP demographic map + surname heuristics (en / es / ht / vi)
  • Generate SMS via Gemini 1.5 Flash ≤160 chars, 6th-grade reading level
  • Enqueue delivery → Cloud Tasks: sms-notifications → CF: send-sms-worker
  • Deliver via Twilio REST API to tenant phone
  • Log: phone stored ONLY as SHA-256 hash — never raw number in any log

Dialogflow CX STT / TTS Twilio Voice 4 Conversation Phases 15 Pages

  • Voice: Tenant calls Twilio → Cloud Run: voice-interface → WebSocket stream

Dataflow Apache Beam Rolling 90d/365d Cloud Scheduler

🧠
BQML Retraining
Module 6B · Cloud Build (weekly)
BigQuery ML Logistic Regression Quality Gate Cloud Scheduler
  • Cloud Scheduler triggers every Sunday 2AM UTC → Cloud Build pipeline
  • Step 1: Validate training data volume (>500 rows required)
  • Step 2: CREATE OR REPLACE MODEL — LOGISTIC_REG, 8 features, auto_class_weights=TRUE
  • Step 3: Quality gate — ML.EVALUATE: precision >0.55, roc_auc >0.65
  • Step 4: Archive snapshot to GCS · Step 5: Log retraining event to BigQuery

Module 7C · Cloud Function (daily)
PII Anonymization SHA-256 Tokens 90-Day Window Compliance Report
  • Cloud Scheduler daily 2AM UTC → Cloud Function: evictionshield-retention-job
  • Query Firestore: eviction_filings WHERE pii_anonymized=false AND age>90d
  • Batch replace tenant_name/phone/email with deterministic ANON_ SHA-256 tokens
  • BigQuery verification: confirm no PII columns in filing_events schema
  • Monthly (1st of month): compliance report JSON → GCS: [project]-compliance/
